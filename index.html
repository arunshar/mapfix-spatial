Abstract

Geospatial coordinates arrive distorted all the time: bad georeferencing, projection mismatches, sensor warp. MapFix is the interactive, clickable face of "detect and undo that distortion." You give it points; it models the distortion as a smooth field, inverts it by fixed-point iteration, and shows the residual error and how much area it recovered, live. It is the lightweight demo of the same distortion-aware geometry theme that runs, at more depth, through the author's satellite-splatting (camera Jacobians) and SAR/optical co-registration work.

Honest scope. This is a single-file interactive MVP (server.py, ~457 LOC) plus a browser front-end, not a trained model. The distortion-and-correction math is real and deterministic and runs; the distortion itself is a synthetic, parametric model (a "Mercator repair" profile with curve/shear knobs), so it demonstrates the method on controllable distortion rather than on real misregistered maps. The OpenAI calls are an optional flavor layer; without a key it falls back to a deterministic summary, so the demo runs offline.

How the correction works

The warp is raw = clean + D(clean); inversion is the fixed-point iteration clean ← raw - D(estimate), which converges when D is a contraction.

The gradient_at routine finite-differences the distortion field for a local 2×2 Jacobian, used to diagnose convergence, conceptually the numerical cousin of the closed-form camera Jacobians in the author's sat-splat work. The LLM never touches the geometry; that stays in the deterministic engine.
